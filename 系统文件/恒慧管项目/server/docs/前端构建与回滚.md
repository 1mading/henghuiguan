# 恒慧管前端构建与回滚（小 B）

## 何时用 built

完成 `frontend/` 工程化改造后，生产可切到构建产物：

1. 安装并构建前端：

```powershell
cd D:\apps\henghuiguan\frontend
npm install
npm run build
```

或在 `server` 目录：`npm run build:web`。

2. `server\.env`：

```env
HHG_FRONTEND=built
FRONTEND_DIST=../frontend/dist
STATIC_DIR=..
```

3. 重启后端。钉钉首页仍为 `https://你的域名/app`，**无需改钉钉开放平台**。

## 自动构建（防踩坑）

`HHG_FRONTEND=built` 时，后端启动会检查：若 `frontend/src`（及 vite 配置等）新于 `dist/index.html`，则自动执行 `npm run build`。

| 环境变量 | 说明 |
|----------|------|
| `HHG_AUTO_BUILD` | 未设时：本地服务器 / 非 production 默认开启；设 `false` 可关闭 |
| 构建标记 | `dist/index.html` 含 `<meta name="hhg-build" content="…">`，便于确认是否最新包 |

本地 / `LOCAL_AS_SERVER` 下 `dist/assets` **不再 7 天长缓存**，减少钉钉/浏览器卡住旧哈希。

**改完前端后仍建议立刻 `npm run build:web` 并 Ctrl+F5**；自动构建是重启后端时的兜底。

## 回滚 legacy

```env
HHG_FRONTEND=legacy
```

重启后端即恢复发放根目录 `恒慧管.html`。

## 发版注意

- 发版流程在覆盖后端后，若使用 built，需多一步 `npm run build:web`。
- `persistHtmlUsers` 在 `built` 模式下**不会**写回 HTML（避免污染 dist）。
- 入口 HTML 仍 `no-cache`；生产非本机模式下 `dist/assets/*` 可长缓存。
- 保留 CSP `frame-ancestors`（钉钉 iframe 防白屏），勿删。
