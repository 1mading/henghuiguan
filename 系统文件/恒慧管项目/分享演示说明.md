# 恒慧管 · 分享演示说明（钉钉登录 / 换电脑可用）

面向 5 分钟 AI 分享：展示**钉钉登录**、项目/任务/团队（信息中心）、工作台，以及**钉钉表单提报进入工作台**。

## 最快方式（推荐）：单文件 HTML

只需拷贝这一个文件到任意电脑，**双击用浏览器打开**即可，无需 Node、无需服务器：

```text
恒慧管项目/恒慧管-分享演示.html
```

可交互内容（界面样式对齐正式 `恒慧管.html`）：

- 钉钉登录引导页 →「本地预演：进入工作台」
- 正式同款侧栏 / 顶栏 / 工作台统计卡与待办卡片
- 项目卡片、任务列表、团队饱和度（仅信息中心）
- 「模拟钉钉表单提报」→ 新待办立刻出现在工作台

> 正式现场仍建议用钉钉工作台打开真实系统做免登；本 HTML 适合预演与离线分享。  
> 需联网加载 Font Awesome 图标（与正式版相同 CDN）；无网时图标可能变成方框，布局不受影响。

## 一、完整服务演示（可选）

若需要连真实后端 / SSE / 接口验签，再用服务版：

### 需要什么

1. 把整个 **`恒慧管项目`** 文件夹拷到目标电脑
2. 目标机安装 **Node.js 18+**（[nodejs.org](https://nodejs.org/)），或已安装 Cursor  
3. 双击启动（任选）：

| 系统 | 入口 |
|------|------|
| Windows | `启动分享演示.vbs` 或 `start-share-demo.ps1` |
| macOS / Linux | `bash start-share-demo.sh` |

然后打开：**http://localhost:3001/app**


## 二、演示数据说明

| 部门 | 人员 | 说明 |
|------|------|------|
| **信息中心** | 总经理 / 经理 / 管理员 / 实施 / 运维 / 研发 | 业务成员；**团队页只展示他们** |
| **财务中心** | 财务经理 / 会计 / 财务联系人 | **仅通知联系人**（不可登录、不进团队页），用于表单提报 |

另含：3 个项目、多条任务、多条「表单提报」样例（财务 → 信息中心工作台）。

团队页只展示信息中心业务成员；财务中心不出现在团队页签。

## 三、模拟再来一条表单

服务启动后另开终端：

```bash
cd 恒慧管项目/server
# Windows
set SHARE_DEMO_BASE_URL=http://localhost:3001
node scripts/simulate-aitable-intake.js

# macOS / Linux
SHARE_DEMO_BASE_URL=http://localhost:3001 node scripts/simulate-aitable-intake.js
```

## 四、5 分钟口播建议

| 时间 | 讲什么 |
|------|--------|
| 0:00–0:40 | 痛点 |
| 0:40–1:20 | 钉钉工作台打开 → 免登（可先展示引导页） |
| 1:20–2:40 | 工作台「表单提报」待办（财务提报） |
| 2:40–3:40 | 团队：信息中心成员饱和度 |
| 3:40–5:00 | 项目与 AI 做出可上线系统的价值 |

重置：再运行一次启动脚本即可重写演示库。
